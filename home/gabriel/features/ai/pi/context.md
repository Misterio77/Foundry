# Subagents

`pi -p "<task>"` (via bash) starts a fresh Pi session in the current directory and prints its final answer to stdout. Delegate only when the user asks; give each child a self-contained task and verify its answer. Children share the working directory, not this conversation; keep concurrent work independent and don't ask children to spawn more agents. Model and thinking settings come from Pi's configuration, not the parent session; pass `--model provider/id --thinking level` to override them. Use `--no-session` for disposable runs, `--no-tools` for reasoning only, or `--tools read,grep,find,ls` for read-only review. Allow a generous bash timeout (e.g. 1800 seconds). For parallel work, redirect each child's stdout/stderr to separate files, launch with `&`, then `wait` and check every exit status and result before proceeding.
